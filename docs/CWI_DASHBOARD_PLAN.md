**Repo:** github.com/SamDuo/CWI-Repo (separate project; NOT Polymetron).
**North star:** GeoLibre (opengeos) — an open, browser-native GIS dashboard. We borrow its
*patterns and open stack*, NOT Polymetron's Atlas style. (Different product, different look.)

## 1. The data we have (CWI.zip)

A **parcel-level Community Wellness Index** for Portsmouth:
- ~36.6k parcels joined to **54 census tracts** (Cen_GEOID); geometry in the parcel `SHAPE`
  column + a QGIS project (`Reprojected_MasterPortsmouth.qgz`).
- **8 weighted domains** (Normalized Index Weights, sum ≈ 1.0):
  Economic 0.146 · Housing/Neighborhood 0.140 · Safety/Crime 0.140 · Education 0.138 ·
  Health/Healthcare 0.134 · Environment 0.114 · Social/Community 0.099 · Infrastructure 0.089.
- **Standardized (0–1 percentile) indicators in the data:** crime points, flood risk,
  bus-stop distance, hospital distance, opportunity-zone flag, walkability, % owner-occupied,
  unemployment, % no-HS-diploma, % in college (+ property value, year built, zoning).
- The `Variables.docx` lists the FULL wish-list per domain; many are flagged **"No Data"** —
  the dashboard must be honest about which domains are well-covered vs sparse.

**Data prep (P0):** compute the composite CWI = Σ(domain weight × standardized domain score)
per parcel and per tract, export to web GeoJSON. (Confirm the exact variable→domain mapping
with the researcher; some domains currently rest on 1 indicator.)

## 2. Two build paths

**Path A — Use GeoLibre directly (fast validation, days).** Load the CWI GeoJSON into GeoLibre
(geolibre.app or self-hosted), configure graduated symbology, legend, and a story map. Almost
no code. Trade-off: limited custom branding, AGPL if self-hosted, less control. Good for a quick
stakeholder preview.

**Path B — Custom dashboard in CWI-Repo (recommended).** Build your own, borrowing GeoLibre's
patterns + open stack. Full control, custom civic branding, your repo, free static hosting.
This plan assumes **Path B** (use A as a throwaway preview if helpful).

---

## 3. Stack (GeoLibre-aligned, distinct from Polymetron)

- **Next.js (App Router) + TypeScript + Tailwind** — but a **new design system** (see §5), not Atlas.
- **MapLibre GL JS** (open, no Mapbox token — civic-friendly) for the basemap + choropleth.
- **deck.gl** (optional) for the 36k-parcel layer at high zoom.
- **shadcn/ui** for components (cards, tabs, selects, sheets) — GeoLibre's component layer; clean,
  neutral, and clearly not Polymetron.
- **Charts:** Recharts or visx for the 8-domain radar / bars.
- **Data:** fully **static GeoJSON** (tract + parcel) generated by a Python prep script — no
  backend, deploys to Vercel/Netlify/GitHub Pages.

---

## 4. Views (borrowed GeoLibre patterns, mapped to CWI)

1. **Map overview** *(GeoLibre symbology + legend)* — graduated CWI choropleth, **tract-level
   default → parcel-level on zoom-in** (the level-of-detail pattern). A metric switcher: overall
   CWI or any of the 8 domains. Classed legend (quantile/equal/Jenks). Missing-data areas hatched.
2. **Area report card** *(GeoLibre attribute inspect + our report-card idea)* — click a tract →
   a panel: the CWI score, an **8-domain radar/bar breakdown vs city median**, the weights, and
   each raw indicator with its source + "No Data" honesty flags.
3. **Compare areas** *(GeoLibre multi-map / split)* — two tracts (or two domains) side by side.
4. **Methodology story** *(GeoLibre story-map builder)* — scroll-driven explainer of the 8
   domains, weights, sources, and limitations. Doubles as the public "how we built this."
5. **Rank & find** *(GeoLibre attribute table)* — sortable tract table by CWI / domain; filter
   "highest / lowest wellbeing," export CSV.
6. *(Later)* **Live styling** (classification/palette/opacity) + **embeddable URL views** —
   GeoLibre's live-styling + `viewer?params` patterns, for sharing with city staff.

---

## 5. Distinct visual direction (civic wellbeing — to confirm)

NOT Polymetron's cool blue-grey + Instrument Serif. A **civic, accessible, optimistic** look:
- **Palette:** warm off-white base; a primary **teal/green** ("wellbeing"); a **colorblind-safe
  diverging** ramp for the index (low ↔ high); amber for caution/no-data.
- **Type:** a friendly civic sans — e.g. **Public Sans** (the US gov / USWDS font) or Inter — for
  body; a warm display (Libre Franklin / Fraunces) for headings.
- **Feel:** soft rounded cards, generous spacing, large accessible type, legend-forward. A public
  dashboard, not an intelligence terminal. (Loosely USWDS-aligned reads "civic" and is clearly
  not Polymetron.)

## 6. Phased build

- **P0 — Data prep & geometry.** Python: CSV × weights → CWI per parcel + per tract; export
  `tracts.geojson` (+ domain scores, weights, sources) and `parcels.geojson`. Validate totals
  against the researcher's numbers. Resolve geometry source (SHAPE/WKT vs QGIS export).
- **P1 — Map overview + legend** (graduated CWI, metric switch, tract→parcel LoD).
- **P2 — Area report card** (radar/bars + indicators + sources + no-data flags).
- **P3 — Compare + rank table.**
- **P4 — Methodology story + live styling + embeddable + deploy.**
